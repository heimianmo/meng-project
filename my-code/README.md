## 先说清楚两件事

**这是 C 语言，不是 C++。** 文件后缀是 `.cpp`，因为 Visual Studio 新建源文件默认给这个后缀；
但代码里全是 `stdio.h`、`malloc.h`、`struct`、指针，没有任何 C++ 语法（没有 `iostream`、`cout`、类、引用）。

**这里只是备份展示。** 平时写代码、编译运行仍然在 `D:\01学习\01C语言`，用 Visual Studio。
每次写完一段，复制一份到这里，再同步到 GitHub，**原始文件从不被改动**。
为了让网页上中文不乱码，副本转成了 UTF-8 编码；要编译请打开 D 盘原文件。

## 以后怎么加新代码

1. 在 Visual Studio 里照常写完、保存（D 盘原目录不动）
2. 把新文件复制进 `my-code/` 下面对应的目录
3. 在仓库根目录双击 `双击上传.bat`，或者手敲三行：

```bash
git add .
git commit -m "这周写了什么"
git push
```

刷新 `github.com/heimianmo/meng-project` 就能看到。
