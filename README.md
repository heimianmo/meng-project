## 怎么跑一下示例

```bash
python examples/vitals_summary.py
```

不需要装任何第三方库，用的是 Python 标准库。它会读一份**虚构的**生命体征数据，
算出均值并标出异常值。这是医学数据处理最基础的一步：先把数据读进来、看懂它。

## 一条必须记住的红线

**永远不要把真实患者数据传上 GitHub。**

病历、DICOM 影像、心电原始信号、带姓名或住院号的表格，一律不行。
公开仓库等于向全世界公开发布，而且 Git 会永久保留历史记录，删掉文件也抹不掉痕迹。
本仓库的 `.gitignore` 已经把常见医疗数据格式挡在门外，但工具只是兜底，习惯才是关键。

练习时一律用公开数据集或自己造的虚构数据。
